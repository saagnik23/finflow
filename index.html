Holdout Test Set Classification Summary
Conservative abstention ensures financial categorization errors are never silently accepted.

The machine learning pipeline couples a n-gram TF-IDF text vectorizer with a multi-class Logistic Regression classifier trained on student financial merchant strings. A high confidence cutoff (0.65) ensures that novel or ambiguous descriptions are routed to the student for confirmation, preventing silent misclassification in financial statements.
